05 / How it works

Nothing is drawn by hand.

The world is made from open data, the moment you arrive.

You go somewhere

Type a place or a coordinate. The game finds where on Earth that is.

A tile service builds it

It cuts a 500 m square out of open data: ground height, water, roads, trees, building outlines and heights.

The plugin makes blocks

The Paper plugin turns the square into chunks: houses with rooms, trees, and 3D landmark models on top.

You walk in

One block is one metre, so a street takes as long to walk as the real one.

Everything it is built from is listed on the data page, and the code is on GitHub.

07 / Questions

The short answers.

If yours isn't here, ask on GitHub.

Is it free?

Yes. You only need Minecraft. The code is public and free to read, run and change for non-commercial use.

Do I need mods?

No. Join with plain Minecraft Java 26.3, or with Bedrock on a phone, console or Windows.

Why do some buildings look like plain blocks?

Most buildings in the open data are only an outline and sometimes a height. Where somebody mapped the parts, or where a city has a real 3D model (Berlin, the Netherlands, and France for heights), you get real shapes. Famous buildings are real models.

Why is a new place slow the first time?

Each 500 m square is built when the first person arrives, from open data on other servers. After that it is kept.

What can't Bedrock players see?

Cars, trains, the stadium, furniture and the floating labels. Those use a feature Bedrock doesn't have. The world, houses and landmarks look the same.

Can I run my own?

Yes, for non-commercial use. The plugin, the tile service and the tools are on GitHub, with the steps. You cannot sell it.

Is it connected to Mojang or Microsoft?

No. It is a fan project. Minecraft is a trademark of Mojang AB.

The code is public.

The plugin, the tile service and the landmark converter are on GitHub under the PolyForm Noncommercial licence: free to read, run and change, not to sell.
